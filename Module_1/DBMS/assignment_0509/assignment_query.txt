10. Implement following using case statement. Use data from emp database.
    If comm is null ‘need improvement’ If <500 “ok” If >=500 and < 1000 ‘good' ‘Excellent'. 
 
--------------QUERY---------------

SELECT ename, sal, comm,
CASE
WHEN comm IS NULL THEN 'Need Improvement'
WHEN comm < 500 THEN 'OK'
WHEN comm >= 500 AND comm < 1000 THEN 'Good'
ELSE 'Excellent'
END AS "Status"
